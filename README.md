# Metro Colo Advisory Open Data

Free, sourced datasets from [Metro Colo Advisory](https://metrocoloadvisory.com/), an independent data center, GPU and cloud advisory firm. Every figure links to its source, and each dataset has a permanent DOI on Zenodo.

## Datasets

| Folder | What it covers | DOI | Dataset page |
|---|---|---|---|
| [copper-retirement](copper-retirement/) | AT&T and Verizon copper landline (POTS) retirement by state: FCC filings, approvals, discontinuance dates and a dated log | [10.5281/zenodo.23620111](https://doi.org/10.5281/zenodo.23620111) | [metrocoloadvisory.com/copper-retirement-data/](https://metrocoloadvisory.com/copper-retirement-data/) |
| [data-center-cost](data-center-cost/) | What it costs to build, lease and run a data center in North America in 2026: cost per MW, cost per watt, lease rates, PUE and power cost, AI hardware prices, vacancy and timelines | [10.5281/zenodo.23652508](https://doi.org/10.5281/zenodo.23652508) | [metrocoloadvisory.com/data-center-cost/](https://metrocoloadvisory.com/data-center-cost/) |

More datasets are on the way, starting with GPU rental prices.

## Updates

Each dataset is updated on its dataset page first, then here and on Zenodo as a new version. The DOI always points to the latest version.
